## App Overview

AssetGuardian is a TW/US equity portfolio tracker with trade journal support, strategy tags, portfolio dashboard, and trend review.

資產管家是一款台股 / 美股投資組合追蹤工具，提供交易日誌、策略標籤、總覽卡片與資產趨勢回顧。

## What You Can Ask For

- App usage questions
- Portfolio data export questions
- Bug reports

## Suggested Support Details

When contacting support, please include:

- App version
- Device model
- iOS version
- A short description of the issue
- Screenshots if available

## Notes

- No account is required to use the core app experience.
- iCloud sync is optional and stores data in the user's private iCloud database.
- Exported CSV files may contain sensitive portfolio data. Please handle them carefully.
